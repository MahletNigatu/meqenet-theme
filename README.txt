MEQENET - Shopify theme v0.7

COLLECTION PAGES NOW HAVE IDENTITY
Every collection page opens with the Addis Abeba treatment: a badge, the title,
an italic line, a rule-led description, and a matted artwork plate. One accent
per collection, so the set reads as a family.

  MEQENET        clay          blush ground      "Try. Fail. Fix the meqenet."
  Kaldi's Goat   gold          parchment ground  "Before anything else, the cup."
  Society        deep ink      cream type, gold italic
  Addis Abeba    sky blue      unchanged

The accent is chosen from the collection handle, so nothing needs configuring.
A new collection line gets the clay default until you tell me its color.

WHERE THE WORDS COME FROM
  Badge and tagline   Written into the theme, per collection.
  Description         Pulled from the collection's own Description field in
                      Shopify - Products -> Collections -> open one -> Description.
                      Leave it blank and the page simply omits it.

  So the one thing worth doing in the admin: paste a description onto MEQENET,
  Kaldi's Goat and Society. Two or three sentences each. Mine from the mockup
  are a starting point if you want them.

THE ARTWORK PLATE
  It uses the collection's own image - Products -> Collections -> open one ->
  Image, top right. Until you set one, the plate shows "Collection artwork" on
  the collection's tinted ground, which looks deliberate rather than broken.

EMPTY COLLECTIONS
  A collection with no products now shows a waitlist form instead of "nothing
  here yet" - exactly the Addis Abeba pattern. Signups are tagged
  <handle>-waitlist in your customer list. Society gets this until it has
  products, then the grid takes over automatically.
